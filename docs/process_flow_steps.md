# 処理フローのステップ定義

以下は図中の矢印の流れに沿った「入力 → 処理 → 出力」のステップです。  
各ステップに、補助データ（校正データなど）を紐付けています。

## ステップ一覧

1. **露光データの回転補正（RadiationSpectraRotator）**  
   - 入力ファイル: `露光データ.spe`  
   - 処理名: 回転中心・回転角度補正  
   - 出力ファイル: `露光データ_回転中心_回転角度.spe`  
   - 補助データ: なし

2. **ODフィルタ校正データ作成（校正準備）**  
   - 入力ファイル: `校正参照用ランプデータ.csv`  
   - 処理名: ODフィルタ校正データ作成  
   - 出力ファイル: `校正用ODフィルターデータ.spe`  
   - 補助データ: なし

3. **スペクトル校正（RadiationSpectraRotator）**  
   - 入力ファイル: `露光データ_回転中心_回転角度.spe`  
   - 処理名: スペクトル校正  
   - 出力ファイル: `校正されたスペクトルデータ.hdf`  
   - 補助データ: `校正用ODフィルターデータ.spe`

4. **Planck fitting による温度算出（PlanckThermoEmulator）**  
   - 入力ファイル: `校正されたスペクトルデータ.hdf`  
   - 処理名: Planck fitting  
   - 出力ファイル: `温度分布・誤差データ.hdf`  
   - 補助データ: なし

5. **二色法による温度算出（PlanckThermoEmulator）**  
   - 入力ファイル: `校正されたスペクトルデータ.hdf`  
   - 処理名: 二色法  
   - 出力ファイル: `温度、誤差データ（図の出力のみ、ファイル出力なし）`  
   - 補助データ: なし

6. **XRDデータ処理（XRDSpotAnalyzer）**  
   - 入力ファイル: `時系列XRDデータ.nxs`  
   - 処理名: XRDデータ処理（cake・pattern生成など）  
   - 出力ファイル: `cake・patternなどXRD処理データ.hdf`  
   - 補助データ: `XRD校正データ.poni`

7. **ラン統合データ生成（LAMBDA-Melting）**  
   - 入力ファイル: `温度分布・誤差データ.hdf`, `cake・patternなどXRD処理データ.hdf`  
   - 処理名: 温度・XRD・圧力などの統合処理  
   - 出力ファイル: `1 runにおける温度・XRD・圧力など処理済みデータ.hdf`  
   - 補助データ: なし
